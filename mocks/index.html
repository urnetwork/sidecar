Shared design language

accent active agent a agent b agent c warn danger
  • All three share one token set (teal accent, system fonts, --radius cards, soft shadow) and a light + dark theme via prefers-color-scheme. Toggle your OS theme to see both.
  • Everything is self-contained: inline CSS + vanilla JS, inline SVG icons/graphs, no external fonts, images, or libraries. Edit any file directly to iterate.
  • Active agents are marked with a green pulsing dot everywhere they appear (web sidebar, graph, phone list).

Open questions to resolve while iterating

  • Activity query language. The search uses a placeholder grammar (harness:claude-code status:active repo:api "auth" last:1h) — we should pin the real field set and operators.
  • Graph semantics. What edges mean (handoffs, shared repos, agent-to-agent messages) and how they're weighted/animated is a design decision shown one way here.
  • Harness injection. The connect flow shows a curl … | sh + ur connect snippet; the exact binary, token flow, and global-vs-per-agent sync model are placeholders.
  • Burner as password manager. The autofill/OS-integration story (how URnetwork registers as a password manager) is implied, not specified.
  • Signed membership. The team console frames URnetwork's edge over Tailscale as generalized "tailnet lock" — this depends on the blind-coordination architecture decision still open elsewhere.
