# Tools drop what users already saved

As of 31 October 2026, users of the top overlapping tools describe a saved rule, a saved note, an approval, a port, or a login that the product then drops. They do not, on the pages that opened, ask for real-time encrypted storage, a new email inbox, team single sign-on, or a text protocol any harness can spawn. The repeated instruction-file complaint is on Claude Code, Cursor, GitHub Copilot, and OpenAI Codex, with different mechanisms and one Codex thread the vendor closed as stale. The repeated “next run is empty” complaint is one thread each on Mem0, Letta, Claude Code, and the reference MCP memory server, plus one Hacker News item about switching tools. The repeated admin-audit complaint is Cursor’s, and it is about tool-call approvals, not prompt text. On tunnels, Tailscale Funnel users keep hitting a three-port public list, and five Cloudflare quick-tunnel users in October 2026 say an email login dies in seconds. Microsoft dev tunnels, Claude’s content-free audit export, Claude in Slack’s message caps, Resend Inboxes, Dust, and Devin are documented limits or new products with no opened user complaint. Reddit threads that looked relevant did not render, so counts below are opened pages only, and one thread is one thread even when several people posted on it.
